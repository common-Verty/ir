버티 자료 위키 · 팀원 시작 안내 (v3)

버튼만 누르면, Claude가 회사 자료를 대신 찾아줍니다

회사 문서 5,800여 건(제안서·RFP·기술문서·발표자료·회의록)이 검색 가능한 형태로 매일 발행됩니다. 이 페이지의 버튼을 위에서부터 차례로 누르면 세팅이 끝납니다.

개발 지식은 필요 없습니다. 처음이라도 10분이면 됩니다.

1구글 드라이브 연결 한 번만

회사(verty.co.kr) 구글 계정으로 Google Drive for Desktop에 로그인하면 G:\공유 드라이브\버티 지식베이스 가 자동으로 보입니다(별도 수락 없음).

① Drive for Desktop 받기 ② 위키 폴더가 열리는지 확인

②가 브라우저에서 열리면 권한은 이미 있는 것입니다. "액세스 요청" 화면이 나오면 회사 계정으로 로그인했는지 확인하고, 그래도 안 되면 김동우에게 알려주세요.

2플러그인 설치 쓰는 앱 하나만

Claude Code 쓰는 분 복사 한 번 · 이후 자동 업데이트

아래 버튼을 누르면 설치 문장이 복사됩니다. Claude Code 대화창에 붙여넣기만 하세요. 설치는 Claude가 대신 합니다.

G:\공유 드라이브\버티 지식베이스\_회사자료_위키\도구_플러그인\Claude_설치지시서.md 를 읽고 그대로 실행해서 버티 팀 플러그인을 설치해줘. G: 드라이브가 없으면 다른 드라이브에서 '버티 지식베이스' 공유 드라이브를 찾아 진행해줘.

"설치 완료" 보고가 오면 그 창을 닫고 새 창을 여세요. 끝입니다. 이후 새 버전은 자동으로 받아오므로 다시 설치할 일이 없습니다.

Cowork(데스크톱 앱) 쓰는 분 파일 받아 설치 · 2분

① 플러그인 파일 받기 (.plugin)
  • ② Cowork 왼쪽 사이드바 Customize(커스터마이즈) → Plugins(플러그인) 탭을 엽니다.
  • ③ 받은 kdw-agent-skills.plugin 파일을 추가(업로드 또는 드래그)하고 설치를 누릅니다.

업데이트는 새 버전 공지가 오면 같은 버튼으로 다시 받아 설치하면 덮어써집니다. Claude Code와 Cowork를 둘 다 쓰면 각각 한 번씩 설치합니다(내용물 동일).

3바로 써보기 누르면 복사됩니다

질문을 누르면 복사됩니다. Claude 대화창에 붙여넣어 그대로 물어보세요.

버티포트 관련 예전 제안서 찾아줘 K-UAM 그랜드챌린지 진행현황 보고 최근 것 요약해줘 UAM 시뮬레이션 용역 과업지시서(RFP) 찾아서 핵심 요건 정리해줘 우리 회사 소개서 최신본 어디 있어? 작년에 낸 발표자료 기반으로 새 발표 초안 잡아줘

잘 안 찾으면 "회사 위키에서 찾아줘"라고 붙여 말하면 됩니다. 개인정보·급여·재무·법무·투자 자료는 검색에서 자동 제외돼 있습니다.

4팀에 자료 올리기 넣기만 하면 끝

공유할 파일을 드롭박스 폴더에 넣기만 하면, 다음 날 아침 자동으로 분류·요약·색인되어 누구나 검색할 수 있게 됩니다. 정리는 자동이므로 폴더를 만들거나 이름을 다듬을 필요가 없습니다.

드롭박스 폴더 열기
  • 탐색기로는 G:\공유 드라이브\버티 지식베이스\_회사자료_위키\팀_드롭박스\ 에 끌어다 놓으면 됩니다. 폴더째 넣어도 됩니다.
  • 다음 날 파일이 이 폴더에서 사라지면 정상입니다(아카이브로 이동·편입된 것).
  • 개인 자료·민감 자료(급여·계약서 원본·개인정보)는 넣지 마세요.

5위키 직접 둘러보기 선택

Claude에게 물어보는 것이 기본이지만, 직접 볼 수도 있습니다. 폴더 안 _팀_안내.md 부터 읽으면 됩니다. 회사자료_인덱스.csv 를 구글시트로 열면 전체 자료를 카테고리·키워드로 필터할 수 있습니다.

  • 해결이 안 되면 화면을 캡처해 김동우에게 보내주세요. 대부분 로그인 문제입니다.
